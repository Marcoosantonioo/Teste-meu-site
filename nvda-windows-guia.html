Layout de teclado Estes atalhos seguem o layout de teclado padrão ("desktop") do NVDA. Alguns comandos mudam no layout "notebook" — por exemplo, Insert + A para leitura contínua.

Como começar

O NVDA (NonVisual Desktop Access) é um leitor de tela gratuito, de código aberto, totalmente funcional e portátil — pode ser instalado no PC ou rodar direto de um pendrive.

Tecla NVDA: por padrão, tanto a tecla Insert do teclado numérico quanto a Insert estendida funcionam como tecla modificadora do NVDA. É possível configurar Caps Lock como tecla modificadora adicional.

Modo de navegação (Browse Mode): usado para ler documentos e páginas web.

Modo de foco (Focus Mode): usado ao preencher formulários ou campos que exigem entrada do usuário. O NVDA alterna automaticamente entre os modos, mas dá para alternar manualmente com Insert + Barra de espaço.

Visualizador de Fala (Speech Viewer): abre uma janela mostrando tudo o que o NVDA está narrando — útil para pessoas videntes que estão aprendendo a testar com o NVDA. Ative em Ferramentas, no menu do NVDA.

Guia revisado em agosto de 2026 (NVDA 2025.3): os atalhos de teclado abaixo continuam os mesmos desde 2023 — as versões recentes trouxeram principalmente melhorias de compatibilidade com o Windows 11, suporte a novos displays em braile e ajustes internos, sem alterar os comandos padrão.

A lista completa de comandos do NVDA está disponível no Guia do Usuário oficial (NV Access).
