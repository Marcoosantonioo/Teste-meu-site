TalkBack para Android — Guia de Referência Rápida

Reunindo em uma única tela o guia de texto (em português) e o guia ilustrado do TalkBack, com todos os gestos, comandos e atalhos de navegação para Android.

Navegador recomendado: Chrome (Android OS 7.0 ou superior), Firefox (versões mais antigas do Android OS) Lista completa de comandos: tinyurl.com/commands-talkback

Como começar

Ativar o TalkBack: vá para Ajustes > Acessibilidade > TalkBack para ativá-lo. Para usar o atalho, vá para Ajustes > Acessibilidade e ative o Atalho pelas teclas de volume — depois é só manter as teclas de volume pressionadas por alguns segundos para ligar ou desligar o TalkBack.

Menu do TalkBack: reúne comandos relevantes em qualquer lugar do dispositivo. Para abrir, deslize para baixo e depois para a direita, ou para cima e depois para a direita. Em dispositivos com gestos com vários dedos*, também é possível tocar com três dedos.

Controles de leitura: ajustam as configurações de leitura, como deslizar para ler por títulos ou por linhas, e alterar a velocidade da fala. Para abrir, deslize para cima e depois para baixo, ou para baixo e depois para cima (ou, com gestos com vários dedos*, deslize com três dedos). Repita o mesmo gesto para alternar entre os controles.

Explorar pelo toque: arraste um dedo pela tela para que o TalkBack anuncie os itens conforme você os alcança.

Comandos de voz: deslize para a direita e depois para cima, aguarde o som de confirmação e diga um comando — por exemplo, "Próximo link". Disponível apenas no TalkBack 9.1 ou superior.

* Gestos com vários dedos — usando três ou mais dedos simultaneamente — estão disponíveis apenas no TalkBack 9.1 ou superior, somente em alguns aparelhos Android, como Google Pixel 3 ou superior, e alguns modelos de outras marcas, como Samsung Galaxy.
Algumas opções de menu e controles de leitura ficam ocultos por padrão — vá em Configurações do TalkBack > "Personalizar menus" para escolher quais mostrar.
O TalkBack varia de acordo com a versão do Android e o navegador em uso; algumas opções podem não estar disponíveis.

O básico

Ícone Ação Gesto / Comando
Ativar ou desativar o TalkBack Segure os botões de volume por alguns segundos (quando a configuração está habilitada)
Abrir o menu do TalkBack Deslize para baixo e depois para a direita, ou para cima e depois para a direita. Ou toque com três dedos (em dispositivos com gestos com vários dedos*)
Percorrer os controles de leitura Deslize para cima e depois para baixo, ou para baixo e depois para cima. Ou deslize com três dedos para a esquerda/direita ou para cima/baixo (MFG*)
— Pausar ou retomar a leitura Toque com 2 dedos
— Começar a ler continuamente a partir do topo Abra o menu TalkBack e selecione “Ler de cima”
— Começar a ler continuamente a partir do próximo item Abra o menu TalkBack e selecione “Ler do próximo item”. Ou toque 3 vezes com 2 dedos
— Ler o próximo item Deslize para a direita
— Ler item anterior Deslize para a esquerda
— Repetir a última frase Abra o menu TalkBack e selecione “Repetir última frase falada”
— Ativar elemento (link, botão, etc.) Toque duplo
— Ir para o próximo título Selecione o controle de leitura “Títulos” e deslize para baixo
— Ir para o próximo marco/região Selecione o controle de leitura “Marcos” e deslize para baixo
— Ir para a região de conteúdo principal Use o link “Pular para o conteúdo principal”, se disponível, ou explore por toque; ou deslize para a esquerda e depois para baixo (ou abra o menu TalkBack e selecione “Tela de pesquisa”)
— Ir para o próximo link Selecione o controle de leitura “Links” e deslize para baixo
— Rolar uma página, menu, etc. Deslize com 2 dedos para cima, para baixo, para a esquerda ou para a direita
— Ir para a tela inicial Deslize para cima e depois para a esquerda
— Voltar Deslize para baixo e depois para a esquerda
— Aplicativos recentes Deslize para a esquerda e depois para cima
— Notificações Deslize para a direita e depois para baixo. Ou deslize de cima para baixo com 2 dedos
— Ir para o link, título, elemento de formulário ou ponto de referência anterior Selecione o controle de leitura desejado e deslize para cima

Leitura de texto

Ícone Ação Gesto / Comando
Dizer a linha anterior Selecione o controle de leitura “Linhas” e deslize para cima
Dizer a próxima linha Selecione o controle de leitura “Linhas” e deslize para baixo
Dizer a partir do cursor Abra o menu TalkBack e selecione “Ler do próximo item”. Ou toque 3 vezes com 2 dedos
Dizer o caractere anterior Selecione o controle de leitura “Caracteres” e deslize para cima
Dizer o próximo caractere Selecione o controle de leitura “Caracteres” e deslize para baixo
Dizer o caractere foneticamente Abra o menu TalkBack > “Configurações do TalkBack” > “Verbosidade” > “Falar letras fonéticas”
Dizer a palavra anterior Selecione o controle de leitura “Palavras” e deslize para cima
Dizer a próxima palavra Selecione o controle de leitura “Palavras” e deslize para baixo
Dizer o parágrafo anterior Selecione o controle de leitura “Parágrafos” e deslize para cima
Dizer o próximo parágrafo Selecione o controle de leitura “Parágrafos” e deslize para baixo
Soletrar palavra Navegue por palavras, abra o menu TalkBack e selecione “Soletrar última frase falada”

Edição de texto

Gestos adicionados no TalkBack 14.0 (2024). Para o menu completo de edição (mover cursor para o início/fim, selecionar tudo etc.), abra o menu de contexto local: deslize para cima e depois para a direita.

Ícone Ação Gesto / Comando
— Iniciar ou encerrar o modo de seleção de texto Toque duplo com 2 dedos e segure
— Alternar a granularidade da seleção (caractere, palavra ou linha) Deslize 3 dedos para a direita ou para a esquerda
— Copiar o texto selecionado Toque duplo com 3 dedos
— Recortar o texto selecionado Toque duplo com 3 dedos e segure
— Colar da área de transferência na posição do cursor Toque triplo com 3 dedos

Tabelas

O TalkBack lê as células da tabela em ordem, da esquerda para a direita, começando pela linha superior.

Ícone Ação Gesto / Comando
Célula à direita Deslize para a direita
Célula à esquerda Deslize para a esquerda
Célula abaixo Explore pelo toque
Célula acima Explore pelo toque

Formulários

Ícone Ação Gesto / Comando
— Próximo elemento de formulário Selecione o controle de leitura “Controles” e deslize para baixo
Selecionar e desmarcar caixas de seleção Toque duplo
Abrir caixa de combinação (combo box) Toque duplo
Navegar pelas opções da caixa de combinação Explore pelo toque ou deslize para a direita ou para a esquerda
Selecionar várias opções Toque duas vezes em cada opção para selecionar ou desmarcar
Alternar seleção de botão de rádio Deslize para a direita ou esquerda até a opção desejada e toque duas vezes para selecionar
— Ajustar controle deslizante para cima ou para a direita Deslize para a direita e depois para a esquerda. Ou deslize para cima
— Ajustar controle deslizante para baixo ou para a esquerda Deslize para a esquerda e depois para a direita. Ou deslize para baixo

Outros comandos

Guia revisado com base no TalkBack 16.2 (nov/2025). Os recursos com Gemini exigem conta Google e conexão à internet.

Ícone Ação Gesto / Comando
— Pesquisar uma palavra ou frase Deslize para a esquerda e depois para baixo
— Digitando Em um campo de edição de texto, arraste o dedo sobre o teclado virtual e solte quando ouvir a letra desejada
— Falar caracteres digitados Nas configurações do TalkBack, ative “Eco do teclado”
— Reformatar documentos para visualização mais simples Chrome: Ajustes > Acessibilidade > “Visualização simplificada para páginas da web”. Firefox: Visualização do Leitor, na barra de URL
— Passar o próximo gesto para o sistema/aplicativo atual Toque duplo com 4 dedos e segure (MFG*)
— Iniciar ou parar a mídia Toque duplo com 2 dedos
— Atender ou encerrar uma chamada Toque duplo com 2 dedos
— Dicas de gestos Configurações do TalkBack > Verbosidade > selecione “Falar dicas de uso”
— Descrever uma imagem com IA (novo no TalkBack 15+) Menu do TalkBack > “Descrever imagem” (usa o Gemini; requer conexão à internet)
— Perguntar ao Gemini sobre a tela atual (novo no TalkBack 16+) Menu do TalkBack > “Ask Gemini” / “Descrever tela”
